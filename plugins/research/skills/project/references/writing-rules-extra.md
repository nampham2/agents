## Rules not applied

The project does not apply these parts of ASD-STE100 to project records.

- **Safety instructions.** STE starts a safety instruction with a clear command or condition.
  Project records contain no safety instructions. This rule is in the public list of STE rules.
- **Warnings, cautions and notes.** STE sets these apart with a fixed layout. Records use plain
  paragraphs. This item is named from memory of the public descriptions of STE.
- **The approved dictionary.** STE allows each word with one part of speech and one meaning. The
  dictionary is part of the standard, so the project cannot ship it. The preferred-word table and
  the project glossary replace a small part of it.

## This list is incomplete

The project has no official copy of ASD-STE100 Issue 9. The owner, ASD, gives a free copy on request
at asd-ste100.org. Replace this list from that copy when you have it. Until then, do not claim that
project records follow ASD-STE100. They follow the project's own rules, which STE inspired.
